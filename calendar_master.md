## Phase skeleton (the ~2-year shape)

### Phase A — Now through the annual exams (~March 2027)
Exams and studies are the priority here — this is still foundational
academic time, not the highest-stakes stretch yet.
- Pre-UT runway first (22 Nov → 5 Dec: reduced coding, no new starts), then
  the governing sequence above
- Continue steady-but-light pace after the UTs: Bro Code + FRIDAY phases +
  one mini-project at a time, on light days only
- Target by the end of Phase A: FRIDAY Phases R, S, 7–8 done; the command-
  routing decision made before Phase 9; calculator and to-do change lists
  applied (after Phase R); mini-projects #1–#3 finished (Downloads
  Organizer, Linked List/Stack/Queue, Function Plotter)
- **Stretch:** FRIDAY Phases 9–10. They carry into Phase B if not reached
- Pandas and the numpy/pandas/matplotlib crash course wait for the bigger
  free window below; numpy/matplotlib are used only as far as the Function
  Plotter and Projectile specs require

### Phase B — Summer break after the annual exams (~April–May 2027)
Your biggest genuinely free coding window before things get serious. Use it
well.
- Finish remaining FRIDAY phases in numeric order: Phase 8 and Phase 9 if
  not done in Phase A, then 10 → 11 → 12 → 13 (voice, OOP refactor, modes,
  remote control). Phase 14 (GUI/HUD) goes to Phase D
- Phase 9 and Phase 11 stay blocked until the routing decision (match-case
  vs registry vs tool-calling) is made
- Linked List/Stack/Queue (#2) must already be done before FRIDAY Phase 11
  (OOP); if it slipped out of Phase A, do it first
- Mini-projects #4 (Projectile Motion) then #5 (Sorting Comparison), if not
  finished in Phase A
- numpy/pandas/matplotlib crash course
- Start portfolio project #1 (data analysis) — a good summer-length project

### Phase C — June 2027 – March 2028 (board + entrance exams)
This is the highest-stakes stretch — board results plus entrance exams
(KCET/COMEDK/JEE or whichever applies) directly decide your engineering
seat. Coding drops to maintenance mode only.
- No new big builds
- Occasional small FRIDAY tweaks or a Bro Code video on a genuinely light
  day, nothing more
- The instinct to keep building here should be resisted — this stretch's
  outcome matters more than any project

### Phase D — Gap between board exams and engineering starting (~April–July 2028)
Board exams usually finish by March, and admission/counseling runs for a
few months after — this is typically another long free stretch. Your big
final push.
- Portfolio projects in order: #2 ML classifier → #3 ML model served via
  API → #4 small CV/NLP project; #5 FRIDAY matured runs throughout
- FRIDAY Phase 14 (PyQt5 GUI/HUD)
- Linear Regression From Scratch (mini-project #6) → sklearn comparison
- Start a second language (C++ or Java) for your DSA coursework, so you're
  not learning syntax and algorithms at the same time in semester 1
- Clean up GitHub repos, write proper READMEs, finalize whatever goes on a
  resume/portfolio page

**The pattern:** two long free windows (Phase B and Phase D) do almost all
the heavy lifting. Phase A is steady-but-light, and Phase C is nearly a
full freeze except for tiny maintenance. Trying to force big project
progress during Phase C is the most likely way to hurt both the projects and
the exams that actually determine which engineering seat you get.
